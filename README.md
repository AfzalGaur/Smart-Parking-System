# 🚗 Smart Parking System

A full-stack smart parking management system with authentication, booking, dynamic pricing, and simulated payments.

---

## 🔥 Features

- 🔐 User Authentication (JWT + hashed passwords)
- 🚗 Real-time Parking Slot Booking
- 🔄 Live Updates (auto refresh)
- 💳 Payment Simulation System
- 🤖 Dynamic Pricing (based on demand)
- 🟢 Available / 🟡 My Slot / 🔴 Reserved UI
- ❌ Secure booking (users can't cancel others)

---

### Frontend

### Backend
